# Ceramic BTI Atlas: headings 6912 and 6913

Static catalogue of all EU Binding Tariff Information (BTI) rulings for CN headings 6912 (ceramic tableware and kitchenware) and 6913 (statuettes and ornamental ceramic articles), 2004–2026: 8,224 rulings, 4,686 with photos.

Live site: https://julymarc.github.io/ebti-ceramics/

Source: European Commission (DG TAXUD) EBTI database — full public export and public ruling pages, retrieved 5 Oct 2026. Photos load directly from the EBTI server. Unofficial compilation, not an EU publication; descriptions are in the issuing authority's language.
